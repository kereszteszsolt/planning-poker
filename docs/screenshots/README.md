## Privacy boundary

Every checked screenshot must:

- use invented participant names, room IDs, estimates, and status text;
- avoid a maintainer's live browser profile, clipboard contents, production room, or private team data;
- hide or replace dynamic timestamps, random IDs, and other unstable values when they are not part of the scenario;
- be visually inspected before commit;
- state whether it was manually captured or generated by the repository workflow.

## Planned implementation

[PP-009](../releases/release-0.2-experience-foundation/stories/PP-009-privacy-safe-screenshot-workflow.md) introduces a dev-only Playwright workflow. The preferred approach is a deterministic test server or transport fixture that exercises the real React interface without reading any live room. Locale, timezone, color scheme, viewport, animations, random IDs, and test data must be fixed.

Visual comparisons should run in the same pinned environment used to create the baselines. Updating a baseline requires a human review of expected, actual, and diff images.
